Entrants send exactly one emoji, the one most likely to make a stranger smile. A judge compares them two at a time and picks the warmer; the emoji that wins the most comparisons takes the reward. This entry sends 😊 — a smiling face with smiling eyes: warm at first glance, readable by anyone with no context, gentle rather than loud, and chosen for the moment instead of being the first smiley that comes to mind.

## Run it

```sh
python3 main.py
```

The program writes exactly one emoji to the path in `OUTPUT_PATH` (default `/output/entry.txt`), with no other text. It is deterministic: no network, no randomness, no input — every run writes the same emoji.
